# Soniclet

<img src="Assets/Preview.png" width="128" height="128" alt="Sonicletのアイコン">

macOSの入出力デバイスをメニューバーから切り替える、小さなネイティブアプリです。[English](README.md)

- 入力・出力デバイスの切替と出力音量の調整。両端の標準ボタンは1/16ずつ増減し、長押しで連続操作できます。音量変更後に短い確認音が鳴り、調整非対応の機器では操作が無効になります
- 設定のチェックで、使わない機器をこのアプリの一覧から非表示に
- メニューバーの右クリックから現在の機器確認・消音・設定・終了
- 設定のアイコン付きドロップダウンで、Soniclet／接続先／スピーカーを選択。初期選択はスピーカーで、見本は現在の音量を反映します。スピーカー表示は機器によらず音量・消音だけを表します。マークは音量に応じて中央の波形が左から点灯し、消音時は3本とも半透明になります
- macOS標準のログイン時起動設定
- システムの言語設定に従う34言語の表示
- GitHub Releasesの新しい安定版をメニューでお知らせ

音声の録音・加工やドライバーの導入は行いません。機器の非表示は、このアプリの一覧にだけ適用されます。

## Homebrew Cask（公開準備中）

GUIアプリ向けのCaskとして、独自Tap `pal4de/tap` での配布を準備しています。GitHub Releasesと同じUniversal ZIPを使います。初回ReleaseとTapのCaskを公開してからインストール可能になります。[配布手順](docs/HOMEBREW.md)

## ビルド

動作対象はmacOS 14以降。ビルドにはSwift 6.4・macOS 27 SDKとIcon Composer用のアセットコンパイラを含むXcode 27が必要です。外部パッケージは不要です。

```sh
./build.sh
./test.sh
open 'Soniclet.app'
```

Apple SiliconとIntel両方の実行形式を作る場合は、`ARCHS='arm64 x86_64' ./build.sh`を使います。Intel実機での動作確認は別途必要です。

生成アプリはローカル検証用のアドホック署名です。Developer ID署名・Appleの公証はまだ行っていません。

旧Sound Switchの表示設定は、Sonicletの設定がまだない場合に限り引き継ぎます。ログイン時起動はSonicletの設定で管理します。

## 制限

AirPlay機器には、先に「システムのサウンド設定…」で接続してください。未接続のHomePodなどを、このアプリから直接検出・接続する機能はありません。

音量調整や消音は機器の対応状況に依存します。アプリ側で独自に出力先を指定している場合、システムの既定デバイス変更が反映されないことがあります。

翻訳には文字列・書式の自動チェックがありますが、全言語について母語話者による確認を終えてはいません。修正を歓迎します。

## 開発と公開準備

[開発方針](AGENTS.md)、[リリース手順](docs/RELEASING.md)を参照してください。設定画面やメニューバーの変更後は、ログイン済みのmacOS環境で`./test-settings.sh`も実行します。

メニューの開閉・配置・外側クリック・Escapeによる閉じる操作は、AppKitのNSMenuに任せています。選択可能な行は標準NSMenuItemを使い、スライダーや案内文などだけにNSMenuItem.view上のSwiftUIを使います。NSPopoverは使っていません。

選択できる機器・コマンドは標準NSMenuItemです。配置・ホバー・押したまま移動して離す選択・キーボード操作・アクセシビリティはAppKitに任せ、独自描画は左の丸い機器アイコンに限定します。選択中の丸はシステムのアクセントカラーに従い、行のハイライト色はAppKitに任せます。macOS 27以降では画像の表示を明示的に指定し、残量は標準のサブタイトル（macOS 14.4以降）に表示し、右端の標準バッジは手動選択の表示に使います。デバイス選択後は標準動作としてメニューが閉じます。閉じる動作を無効化する公開APIはmacOSでは利用できないため、独自行やメニューの開き直しによる回避策は採っていません。切り替え待ちの無効な行だけは、左にスピナーを置く小さなビューを使います。並べ替えはmacOS 27以降の標準reorderable / reorderContainerを使い、行の持ち上げと挿入位置の表示をシステムに任せます。同じ形と音量だけの変化はアニメーションせず、消音切り替えはmacOS 15以降でMagic Replace、macOS 14では標準の置換効果を使います。

設定画面は「一般・出力・入力」の3タブです。一般にアイコン・ログイン時起動・更新確認、出力／入力にそれぞれの機器表示・並び順・自動選択を配置します。macOS 15以降は標準SettingsシーンとSwiftUIのTabView／Tabを使い、macOS 14向けにはtabItemを残します。各ページは標準の角丸カード形式です。出力／入力では、自動選択の標準スイッチと機器一覧を別セクションに分けています。macOS 27以降では機器の行をドラッグして入出力別の表示順を変更できます。コンテキストメニューの「上へ移動」「下へ移動」も利用でき、旧OSではこの上下移動を使います。順序はUIDで保存し、再接続後も維持します。並べ替えで音声経路は変わりません。自動選択は入力・出力別に有効化できます（初期値はオフ）。表示中の接続機器を上から優先し、非表示の機器は候補から除外します。

AirPods・Beats・スピーカーなどの対応範囲は[機器アイコン一覧](docs/DEVICE-ICONS.md)を参照してください。専用シンボルや機種情報がない場合は、種類に合う標準記号に戻します。

## ヘッドフォンとバッテリー

接続先表示は、識別できるヘッドフォンの機種を含む現在の出力機器の記号を使います。スピーカー表示は音量・消音だけを示し、Soniclet表示はアプリのマークを保ちます。

残量はmacOS標準の`system_profiler`が返す、接続中のBluetooth機器情報から読み取ります。同じ接続では最短1分間隔で、メインスレッド外から取得します。生のレポートは保存・送信しません。

取得できた残量だけを表示します。左右別のイヤホンでは取得できた左右の低い方を使い、ケースの残量をイヤホンの残量として表示することはありません。WH-1000XM3のように、Appleのメニューでは表示されてもこの標準レポートに残量が出ない機器では、空欄になります。

Appleのヘッドフォン接続中は、デバイス名付きの項目から、その機器専用のOS設定パネルへ移動できます。設定URLの遷移先はmacOSの挙動に依存し、OS更新で変わる可能性があります。その他のBluetoothオーディオ機器や古いmacOSではBluetooth設定へ移動します。ノイズコントロール・空間オーディオ・会話感知はシステム設定に任せます。

## 更新確認とプライバシー

起動時とメニューを開いた時に、1日1回までGitHub Releasesを確認します。手動確認もできます。新しい安定版がある場合はメニューに表示し、クリックすると該当するリリースページを開きます。自動ダウンロードやインストールは行いません。

GitHubへアプリのバージョンを含む通常のHTTPSリクエストを送りますが、デバイス名・音声・音量設定は送りません。自動確認の通信エラーは通知せず、手動確認では結果を表示します。

Icon Composerの原稿と旧macOS向けアイコンを同梱しています。Developer Program加入と証明書の準備が完了し、0.7.9 (23)のローカル配布用Universal ZIPはDeveloper ID署名・Apple公証・チケット添付・Gatekeeper検証まで通過しました。[対象アーカイブの記録](docs/VALIDATION.md)を参照してください。既定のローカル／CIビルドは、署名証明書を指定しない限りアドホック署名のままです。

ライセンスは[MIT](LICENSE)です。

並べ替えはmacOS 27以降の標準 `reorderable` / `reorderContainer` を使用します。旧OSでは行のコンテキストメニューから上下移動できます。確認状況は [docs/VALIDATION.md](docs/VALIDATION.md) を参照してください。

自動選択中は優先順位を更新し、手動選択中に上位候補が現れたら、メニューを閉じていても標準ダイアログで確認します。同じ候補・順序で確認を繰り返さず、手動選択した機器が切断されたら自動に戻ります。自動の出力切り替え成功後は接続先のアイコンを約2秒表示して元へ戻ります。入力だけの変更ではスピーカーを表示し、出力のプレビュー中は入力の変更で上書きしません。再起動後は、有効な方向の自動選択を再開します。外部アプリによる既定機器の変更は、接続変化を伴わない場合に手動選択として扱います。

切り替えは変更通知とUIDの読み戻しで確認し、最大約5秒の反映待ちと約0.5秒の安定確認を行います。自動の入出力切り替えは順番に処理します。反映未確認・失敗でもモードを変えず、同じ接続・優先順位での無限再試行を防ぎます。

自動選択が有効な入出力を手動指定している場合、メニューの「Sonicletの設定…」の直上に「自動選択に戻す」を表示し、手動指定をまとめて解除できます。自動選択をオフにしている方向の設定は変えません。

設定画面の「一般」からも更新確認を実行できます。メニューと同じ更新状態・チェック処理を共有します。

App Store向けのSandboxビルドは `DISTRIBUTION_CHANNEL=app-store ./build.sh` で作成できます。通常版とは別の `.build/app-store/Soniclet.app` に出力し、GitHub更新確認は無効にします。Bluetooth権限を使い、公開IOBluetooth APIのキャッシュから機種別アイコン・専用設定リンクに必要な情報を取得します。この経路では残量は取得できず空欄になります。通常版の残量表示は従来どおりです。権限や情報がない場合もCore Audioのアイコンと汎用設定リンクを使用できます。[検証結果](docs/SANDBOX.md)を参照してください。
